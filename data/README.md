# Data

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains anonymized information about e-commerce orders, customers, products, sellers, payments, reviews, and delivery data.

## Source

Dataset source:
Brazilian E-Commerce Public Dataset by Olist on Kaggle

## Raw Files

The original dataset contains multiple CSV files, including:

- olist_customers_dataset.csv
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- olist_geolocation_dataset.csv
- product_category_name_translation.csv

## Main Tables Used

The main analysis in this project focuses on:

- Customers
- Orders
- Order Items
- Products
- Payments

Additional tables may be used for extended analysis later.

## Notes

The dataset is anonymized and is used only for educational and portfolio purposes.
